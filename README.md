# 思维方法手册

这个仓库整理了一组常见的思维方法，方便按主题快速浏览、对照和回看。

## 如何使用

你可以把它当作一个简明的思维工具箱：

- 想拆解问题时，从不同分类中寻找合适的切入方式。
- 想复盘判断过程时，对照这些方法检查自己遗漏了什么。
- 想系统积累思考框架时，按分类逐步阅读对应条目。
